# AI Influencer Demo

## Overview
This project is a prototype AI influencer workflow designed to explore how generative AI can be used to create digital personalities for social media platforms.

## Concept
The AI persona “Nura” is designed as a student-focused digital creator who shares study, productivity, and career advice for Gen Z audiences.

## Workflow
1. Designed AI persona identity and branding
2. Generated realistic avatar images using generative AI
3. Created short-form script content
4. Generated AI voice narration
5. Combined media assets into TikTok-style short video

## Tools Used
- ChatGPT
- AI image generation tools
- ElevenLabs / text-to-speech
- Canva / CapCut
- GitHub

## Goals
- Explore realistic AI influencer generation
- Test social-media-ready AI content workflows
- Understand consistency between persona, voice, and content style
